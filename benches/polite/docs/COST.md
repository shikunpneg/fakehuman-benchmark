# 《讲文明》成本估算（COST）

> 每次新建 benchmark 都给出成本估算。本表基于 `benchkit.estimate`，价格为**估算值**
> （以各厂商官方计费页为准，2026 峰谷定价波动大）。跑全量前先用
> `python -m benchkit.estimate --bench polite --provider <p> --model <m>` 复核。

## 选用模型：最便宜的档位

- **Provider**：`ark`（火山方舟 / 字节豆包），对应 `.env` 的 `doubao_api_key`。
- **Model**：`doubao-seed-2-0-mini-260428`（seed 2.0 mini 档）。
  > `doubao-seed-2-0-lite-260428` 在本账户未开通（Ark 返回 `ModelNotOpen` 404），
  > 故选用**同厂已开通、仍属低价档**的 `doubao-seed-2-0-mini`。
- **计价（估算）**：输入 `¥0.3/百万`，输出 `¥0.6/百万`。若之后在 Ark 控制台开通了
  `seed-2-0-lite`（入 0.2 / 出 0.4），会更便宜，可把默认模型切回它。

## 全量成本估算（v0.1，40 条刺激）

| 参数 | 值 |
|---|---|
| 刺激条目数 | 40（min 20 + max 20） |
| 每条重复 | 3 |
| 受测模型数 | 1 |
| 调用次数 | 40 × 3 × 1 = **120** |
| 每条输入 token（估） | 40 |
| 每条输出 token（估） | 120（回应多为中长句） |
| 输入 tokens | 4,800 |
| 输出 tokens | 14,400 |
| 单价 入/出 | 0.3 / 0.6 元/百万 |
| **预计总成本** | **≈ ¥0.010** |

## 成本缩放

| 场景 | 调用数 | 预计成本 |
|---|---|---|
| 1 模型 × 3 reps | 120 | ≈ ¥0.010 |
| 1 模型 × 20 reps（稳定性） | 800 | ≈ ¥0.067 |
| 4 模型 × 3 reps | 480 | ≈ ¥0.040 |
| 4 模型 × 20 reps | 3,200 | ≈ ¥0.27 |

结论：**《讲文明》是极低成本的评测**（刺激短、输出短、用最便宜模型），
全量 4 模型 × 20 reps 也不过 ¥0.2 量级。若换 DeepSeek（入 2 / 出 8 元）会在
~¥0.2 基础上高 ~10 倍，但不构成成本障碍。真正要控制的是**调用次数**（条目数 × rep），
而非单价。

> 注：以上 token 估算为粗估。实际以 `results/raw/*.json` 里的 `usage` 为准；
> 采集后会得到真实 token 数，可回填本表。
