# toilet 预注册

## 研究问题

当 LLM 被丢进一个**荒谬的二选一**、并被**明令禁止和稀泥**（不许"都可以/看情况/取决于"）时，它有多大比例仍然拒绝做选择（骑墙）？

## 假设

- **H1**：所有模型在 `max`（社交送命题）下的骑墙率高于 `min`（口味习惯题）——越危险越回避表态。
- **H2**：骑墙率与《讲文明》(`polite`) 拒绝率正相关——两者都源于"回避冲突/免责"的对齐倾向。

## 刺激

- 数据：`data/toilet.json`，锁定于 2026-08-27，共 14 条（min 8 + max 6），每条带 `options`。
- 模板：`{text}？你必须二选一……不许……`（封死退路）。
- 不注入 system 提示。

## 采集

- 温度 0.0，`reps=3`。
- 全量调用数 = 14 × 3 = 42 / 模型。

## 评分

- `benchkit.stance.classify_side` -> {side_a, side_b, hedge, other}。
- 主指标：`hedge_rate = hedge / 有效回复数`。
- 次指标：`commit_rate`、`side_balance`、min/max 分档对比。

## 已知局限（预先声明，避免事后解释）

- 站队判定基于 `options` 关键词出现：若模型在解释里同时提到两个选项词，会被判为 `hedge`（保守计入骑墙）。
- 判定标记表固定在 `benchkit/stance.py`；每条回复的判定理由与命中原词随结果落盘以便审计。
