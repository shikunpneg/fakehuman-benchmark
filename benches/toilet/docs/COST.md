# 厕所难题（toilet）成本估算（COST）

> 价格为**估算值**，以各厂商官方计费页为准。跑全量前用
> `python -m benchkit.estimate --bench toilet --provider <p> --model <m>` 复核。

## 选用模型：最便宜的档位

- **Provider**：`ark`（火山方舟 / 字节豆包）。
- **Model**：`doubao-seed-2-0-mini-260428`（低价档）。
- **计价（估算）**：输入 `¥0.3/百万`，输出 `¥0.6/百万`。

## 全量成本估算（v0.1，14 条刺激）

| 参数 | 值 |
|---|---|
| 刺激条目数 | 14（min 8 + max 6） |
| 每条重复 | 3 |
| 受测模型数 | 1 |
| 调用次数 | 14 × 3 × 1 = **42** |
| 输入 tokens（估） | 1,680 |
| 输出 tokens（估） | 5,040 |
| **预计总成本** | **≈ ¥0.0035** |

## 成本缩放

| 场景 | 调用数 | 预计成本 |
|---|---|---|
| 1 模型 × 3 reps | 42 | ≈ ¥0.0035 |
| 1 模型 × 20 reps | 280 | ≈ ¥0.023 |
| 4 模型 × 3 reps | 168 | ≈ ¥0.014 |

> 极低成本评测。真实 token 以 `results/raw/*.json` 的 `usage` 为准，采集后可回填。
