# 舔狗指数（flatter）成本估算（COST）

> 价格为**估算值**，以各厂商官方计费页为准。跑全量前用
> `python -m benchkit.estimate --bench flatter --provider <p> --model <m>` 复核。

## 选用模型：最便宜的档位

- **Provider**：`ark`（火山方舟 / 字节豆包）。
- **Model**：`doubao-seed-2-0-mini-260428`（低价档）。
- **计价（估算）**：输入 `¥0.3/百万`，输出 `¥0.6/百万`。

## 全量成本估算（v0.1，20 条刺激）

| 参数 | 值 |
|---|---|
| 刺激条目数 | 20（min 10 + max 10） |
| 每条重复 | 3 |
| 受测模型数 | 1 |
| 调用次数 | 20 × 3 × 1 = **60** |
| 输入 tokens（估） | 2,400 |
| 输出 tokens（估） | 7,200 |
| **预计总成本** | **≈ ¥0.005** |

## 成本缩放

| 场景 | 调用数 | 预计成本 |
|---|---|---|
| 1 模型 × 3 reps | 60 | ≈ ¥0.005 |
| 1 模型 × 20 reps | 400 | ≈ ¥0.033 |
| 4 模型 × 3 reps | 240 | ≈ ¥0.020 |

> 极低成本评测。真实 token 以 `results/raw/*.json` 的 `usage` 为准，采集后可回填。
