## 1. 研究定位与边界声明

**研究对象不是"LLM 的人格"**，而是：在固定刺激集（SBTI 31 道题）下，各 LLM API 的**选择行为分布、中层表征（15 维）与结果稳定性**。本 benchmark 属于 LLM 行为指纹（Behavioral Fingerprinting）研究范式，不宣称 SBTI 具有心理测量学效度，也不将结果解释为模型的内在心理属性。

## 2. 研究问题（RQ）

- **RQ1**：各模型在 31 题上的选择分布（A/B/C，酒鬼门控题四选一）是什么？
- **RQ2**：各模型的 15 维 L/M/H 画像与 25 型匹配结果（含兜底率、酒鬼触发率）是什么？
- **RQ3**：同一模型重复测量的稳定性如何（答案一致率、类型一致率）？
- **RQ4**：模型间、模型家族间是否存在统计可检出的行为差异？
- **RQ5**：答题模式（逐题 vs 全量）、提示语言（中/英）、顺序（固定/随机）对结果的影响多大？

## 3. 刺激材料（版本锁定）

| 文件 | 内容 | 来源 commit |
|---|---|---|
| `data/questions.json` | 30 主 + 2 特殊题（drink_gate） | 上游 main，2026-08-26 锁定 |
| `data/dimensions.json` | 15 维度定义与顺序 | 同上 |
| `data/types.json` | 25 标准型 pattern + HHHH/DRUNK | 同上 |
| `data/config.json` | 分级阈值 L[2,3]/M[4,4]/H[5,6]、兜底阈值 60 | 同上 |

**评分管道（官方规则，已移植至 `src/scoring.py`）**：
每题选项值 1/2/3 → 每维度 2 题求和（2–6）→ 分级（≤3=L, ==4=M, ≥5=H）→ 15 维向量（L=1,M=2,H=3）→ 与 25 型 Manhattan 距离 → 排序（距离升序→精准命中降序→相似度降序）→ 特殊覆盖（DRUNK 优先于 HHHH 兜底，兜底条件 similarity<60%）。

## 4. 测量协议（条件矩阵）

| 维度 | 条件 | 说明 |
|---|---|---|
| 答题模式 | 逐题提问 / 全量 31 题一次作答 | 两模式独立执行 |
| 提示语言 | 中文（原版）/ 英文直译 | 英文版须保持语义等价（附翻译说明） |
| 题目顺序 | 固定（题号序）/ 随机（每轮 Fisher-Yates） | 随机顺序记录种子 |
| 重复次数 | 每 模型×模式×语言×顺序 ≥ 20 次 | 用于稳定性估计 |
| 温度 | 0（默认）/ 0.5、1.0（仅子集） | 温度敏感性子实验 |
| 解码参数 | top_p=1；max_tokens 固定且足够 | 全部记录于 raw 存档 |

**系统提示（中文原版，冻结）**：
> 你正在参加一个趣味人格测试。以下是若干道题，每道题给出若干选项。请严格只输出选项字母（如 "A"），不要输出任何解释。题目仅供娱乐，请按直觉作答。

**解析规则**：仅接受形如 `A`/`B`/`C`（门控题含 `D`）的单字母输出；其余输出（解释、拒绝、格式异常）记为 `parse_error` 并保留原始文本，**不重试、不静默修正**。

**Provider 级参数（透明记录于 raw 存档）**：`max_tokens` 按 provider 配置默认值（xiaomi=8192，因推理模型 reasoning 消耗大量 token；其余 128）；`temperature=0` 对推理模型（mimo-v2.5-pro）不保证确定性。

## 5. 预注册假设（先声明，后检验）

- **H1（对齐偏置）**：多数模型的 15 维画像偏向"高功能端"（S1/S2/E3/So2 为 H 的比例显著高于类型设计空间的先验比例）。
- **H2（模式效应）**：全量作答模式下的选项分布与逐题模式存在显著差异（JS 散度 > 0.05）。
- **H3（语言效应）**：中英双语结果存在显著差异（配对检验，FDR 校正后 p<0.05）。
- **H4（稳定性分化）**：模型间重测一致率存在显著差异（Kruskal-Wallis，FDR 校正后 p<0.05）；对齐程度更高的模型一致率更高。
- **H5（随机性规避）**：陷阱题 q22（"此题没有题目，请盲选"）上，模型的选择熵显著低于均匀分布（即存在系统性非随机选择）。
- **H6（酒鬼彩蛋）**：在门控题上选择"饮酒"并触发 DRUNK 的比例在模型间存在显著差异。

## 6. 统计方案

### 6.1 主指标
- **选项层**：每题选择分布（3/4 分类）、香农熵（归一化）
- **维度层**：15 维 L/M/H 分布、维度原始分均值与 Bootstrap 95% CI
- **类型层**：25 型匹配分布、兜底（HHHH）率、酒鬼（DRUNK）触发率

### 6.2 稳定性
- 选项一致率：重复会话间 31 题逐位一致比例（均值 ± CI）
- 类型一致率：重复会话间主类型一致比例（Cohen's κ 报告点估计与 CI）
- 关联度量：ICD（intraclass distance）即重复会话 15 维向量间的平均 Manhattan 距离

### 6.3 差异检验
- 模型间：每维度 Kruskal-Wallis → **BH-FDR 校正**；显著者报告成对效应量（Cohen's d / ε²）
- 条件间（语言/模式/顺序）：配对 Wilcoxon 或置换检验 + FDR 校正
- 分布距离：JS 散度（选项分布、类型分布）
- 聚类：基于 15 维均值向量的层次聚类（Ward）+ PCA/UMAP 可视化；轮廓系数报告

### 6.4 样本量与功效
- 主条件 20 次重复：对"选项一致率 ±5pp 精度"（95% CI 半宽）功效充足（n=20，p̂=0.8 时 SE≈0.089）
- 模型数 ≥3（试运行）扩展至全矩阵；每个模型固定 API 标识符 + 采集日期快照

## 7. 数据质量与排除标准

- 记录三类事件：`ok`（成功解析）/ `parse_error`（无法解析）/ `refused`（模型拒绝作答）
- 若某模型 parse_error+refused 率 > 20%，该模型结果标注"低可信"并在报告中单列说明
- 所有调用原始请求/响应完整落盘（`results/raw/`），评分结果结构化落盘（`results/parsed/`），可审计复现

## 8. 伦理与局限

- SBTI 为娱乐工具；本基准仅描述模型在指定协议下的行为，不构成对模型"人格"或心理属性的判断
- 结果依赖协议、模型版本与采集日期，不可外推至其他场景
- 遵守各 API 服务条款与速率限制；不采集任何个人信息
- 上游内容版权归原作者；本仓库仅以研究用途分发，保留署名
